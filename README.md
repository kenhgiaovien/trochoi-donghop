# Đồng Hợp Smart Learning Games

App trò chơi học tập của Trường THCS Đồng Hợp (Tam Hợp, Nghệ An): 51 trò chơi, 5 công cụ lớp học, soạn câu hỏi bằng AI Gemini miễn phí (mỗi giáo viên dùng khóa API riêng), giao bài bằng đường link và bảng điểm.

- Chỉ gồm một tệp `index.html`, không có máy chủ.
- Bài học, danh sách lớp, bảng điểm lưu trong trình duyệt của từng máy.
- Kho này **không chứa** thông tin học sinh. Không tải danh sách học sinh lên đây.
